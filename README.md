| Area | In depth |
|------|----------|
| **Full-stack web** | Next.js App Router with Server Components, Route Handlers and middleware; React Compiler; Tailwind v4 design systems with light/dark themes; Monaco code editor embedded in-app |
| **Database** | PostgreSQL on Supabase with 140+ versioned migrations, Row Level Security policies, SQL functions and triggers, Realtime subscriptions, Storage, Auth (email OTP, Google, Apple) |
| **Background work** | Redis + BullMQ job queues and workers, Supabase Edge Functions (Deno) on cron, scheduled GitHub Actions for syncs, cleanup, backups and retention |
| **AI engineering** | Multi-provider LLM setup (Claude, Gemini, Groq) with cost control; structured extraction from resumes and JDs; AI agent workflows; PDF/DOCX parsing (unpdf, pdf-lib, mammoth) and OCR |
| **ML / ranking** | Python recommendation engine combining TF-IDF, sentence embeddings (MiniLM), fuzzy matching, eligibility rules and multi-route retrieval; in-browser embeddings with Transformers.js |
| **Code analysis** | tree-sitter parsers (JS, TS, Python, Go, Java, C++, Rust) to analyse real code from public GitHub profiles |
| **Browser automation** | Playwright agent that fills job application forms across ATS platforms; Chrome extension with versioned feature gates |
| **Mobile** | Expo / React Native app for iOS and Android: push notifications, home-screen widget, voice input, offline SQLite cache, OTA updates, Google and Apple sign-in |
| **Real-time & media** | Supabase Realtime and Web Push across devices, Agora video calls, MediaPipe vision in the browser, WebSockets |
| **Scraping** | Go service that collects job listings on a dedicated server, managed with systemd |
| **DevOps** | Dockerised services, AWS EC2 and S3 (presigned uploads), CI/CD with GitHub Actions to testing and production, Vercel, Turborepo + pnpm monorepos |
| **Payments & messaging** | Razorpay payments, transactional email (Nodemailer), WhatsApp bot |
| **Quality & security** | TypeScript strict mode, ESLint, unit tests, Sentry error tracking, PostHog analytics, RLS and secrets audits |
